## 2. 底盘已占用：保持不变

即使选择单轮 PID 模式，`chassis_ctrl_init()` 也会初始化全部四轮、四路编码器和 IMU。以下共 **20 个信号引脚**，不包括核心板存储器、启动、SWD 和电源等板级占用。

| 功能 | 当前接线 | 外设资源／主板接口 |
| --- | --- | --- |
| 左前轮 LF | PWM C11；DIR C10 | PWM2 子模块 2 B；P9 |
| 右前轮 RF | PWM D3；DIR D2 | PWM2 子模块 3 B；P9 |
| 左后轮 LB | PWM C6；DIR C7 | PWM2 子模块 0 A；P8 |
| 右后轮 RB | PWM C8；DIR C9 | PWM2 子模块 1 A；P8 |
| LF 编码器 | A=C5；B=C25 | QTIMER2_ENCODER2；编码器 4／P10 |
| RF 编码器 | A=C3；B=C4 | QTIMER2_ENCODER1；编码器 3／P11 |
| LB 编码器 | A=C0；B=C1 | QTIMER1_ENCODER1；编码器 1／P13 |
| RB 编码器 | A=C2；B=C24 | QTIMER1_ENCODER2；编码器 2／P12 |
| IMU660RB | SCK C23；MOSI C22；MISO C21；CS C20 | SPI4；姿态传感接口 P3 |

四路电机 PWM 当前为 **17 kHz**。PIT_CH0 为 5 ms 姿态与主循环节拍，PIT_CH1 为 20 ms 底盘闭环；RTWDOG 保留。它们不属于本次新增外设的资源池。

供接线复核的 H2 第 4 页针号：

| 连接器 | 针号 → 网络 |
| --- | --- |
| P8 电机信号 1 | 1=C8；2=C6；3、4=GND；5=C9；6=C7 |
| P9 电机信号 2 | 1=D2；2=C10；3、4=GND；5=D3；6=C11 |
| P13 编码器 1 | 1=GND；2=3V3；3=C0；4=C1；5、6=NC |
| P12 编码器 2 | 1=GND；2=3V3；3=C2；4=C24；5、6=NC |
| P11 编码器 3 | 1=GND；2=3V3；3=C3；4=C4；5、6=NC |
| P10 编码器 4 | 1=GND；2=3V3；3=C5；4=C25；5、6=NC |

### 3.1 常用候选接头的针号

依据 H2 第 4 页；电源针与信号针要分开理解。

| 接头 | 1 脚 | 2 脚 | 3 脚 | 4 脚 |
| --- | --- | --- | --- | --- |
| P16 舵机 1 | C30 信号 | VCC_Servo | GND | — |
| P17 舵机 2 | D0 信号 | VCC_Servo | GND | — |
| P18 舵机 3 | D1 信号 | VCC_Servo | GND | — |
| P5 UART4 | VCC_5V_EXT | GND | C17／MCU RX | C16／MCU TX |
| P15 UART1 | VCC_5V_EXT | GND | B13／MCU RX | B12／MCU TX |
| P4 超声波 | 3V3 | B9／Trig | B10／Echo | GND |
| P21 磁铁检测 | D4 | 3V3 | GND | — |

三个舵机口共用 `VCC_Servo` 电源，各信号串联 100 Ω 电阻。调节该电源会同时影响三个接口，不是每口单独调压。UART 的 5 V 电源针不表示 TX／RX 信号可接 5 V；外设 TX 接 MCU RX，外设 RX 接 MCU TX。

## 4. PWM 资源约束

依据当前 `zf_driver_pwm.h` 第 45–47 行及 `pwm_init()` 实现：同一子模块 A／B 只能同频；同一通道的多个引脚是复用选项，并非多个独立输出。初始化共享子模块还可能重设已有输出，不能只看引脚名不同。

| PWM 资源 | 当前／候选引脚 | 结论 |
| --- | --- | --- |
| PWM2 子模块 0–3 | 底盘四路 PWM | 全部保留；不得用于新增低频控制 |
| PWM2 子模块 3 A | B0／C18／D2／B9 | D2 已作 RF 方向；其余脚即使未初始化，也不能视为独立低频 PWM |
| PWM2 子模块 3 B | B1／C19／D3 | 与 RF 电机 D3 是同一 PWM 通道，禁止重新分配 |
| PWM1 子模块 0 | A=D12；B=D13 | 软件候选；与 SPI1／IIC3 复用，两路同频 |
| PWM1 子模块 1 | A=D14；B=D15 | 软件候选；与 SPI1 复用，两路同频 |
| PWM1 子模块 2 | A=D16；B=D17 | 软件候选；与 UART8 复用，两路同频 |
| PWM1 子模块 3 | A=B10／C16／D0；B=B11／C17／D1 | 模式 4 使用 D0／D1，名义 50Hz；不能另从别名引脚分配独立 PWM；B11 已接蜂鸣器电路 |
| PWM4 子模块 0／1 | B24／B25 | 软件候选；占用时会影响 CSI 摄像头数据引脚 |
| PWM4 子模块 2 | C30 | 对应主板舵机 1，独立于电机 PWM2 |
| PWM4 子模块 3 | C31 | SDK 候选，主板三个标准舵机口没有此脚；需另核对可接出的物理位置 |
| PWM3 | SDK 注明被 SDRAM 占用 | 不列入新增资源池 |

因此“三个舵机插座”不代表三个独立 PWM 频率域：C30 独立，D0 与 D1 共用一个频率域。UART4 使用 C16／C17、PWM 使用 D0／D1 时，属于不同引脚和不同外设，可作为并行候选；不能把 C16 与 D0 或 C17 与 D1 当成独立 PWM 通道，也不能让同一个引脚同时承担 UART 和 PWM。

泵阀开关模式 4 采用名义 50Hz、关约 544μs／开约 2400μs，还原吸盘 PDF 的 Arduino `Servo.write(0/180)` 默认示例；它们是初始测试参数，尚未实测开关门限。BDS300 仍未分配控制参数，不沿用该开关波形。

## 5. 其他软件复用候选

以下表示当前 SDK 支持的候选，不保证主板有同名专用插座，也不意味着可同时使用。

| 外设 | 引脚候选 | 约束 |
| --- | --- | --- |
| UART2 | TX B18／RX B19 | 与 ADC／屏幕并口复用 |
| UART3 | TX B22／RX B23 | 与 CSI／运放 ADC／IIC3 复用；另一组选项 C8／C9 已属底盘，排除 |
| UART4 另一组 | TX D0／RX D1 | 模式 4 已用于泵阀 PWM，不能同时启用该组选项；不构成第二个独立 UART4 |
| UART5 | TX C28／RX C29 | CSI 摄像头配置口；复用前须核对视觉方案和已有回调 |
| UART6 | TX B2／RX B3 | 与屏幕 SPI3 复用 |
| UART8 另一组 | TX B26／RX B27 | 与 CSI 数据等复用，不构成第二个独立 UART8 |
| IIC1 | SCL B16 或 D4；SDA B17 | 与 SPI 无线 RST／INT、磁铁接口等复用 |
| IIC3 | SCL B23 或 D12；SDA B22 或 D13 | 与 UART3、CSI、ADC、SPI1、PWM1 复用 |
| IIC4 | SCL B12；SDA B13 | 与 UART1 共用引脚 |
| SPI1 | SCK D12，MOSI D14，MISO D15，CS 可选 D13／D26／D27 | 与 PWM1、串口无线控制脚等复用 |
| SPI3 | SCK B0 或 B31；MOSI B1 或 B30；MISO B2 或 B29；CS B3 或 B28 | 与屏幕、UART6、CSI 等复用；作为 SPI 用不等于占用 PWM2，但不可同时复用 |
| ADC | ADC1 提供 B12–B27；ADC2 提供 B16–B31 的枚举通道 | 每脚仍须核对板上连接及输入电压；板载运放输出只对应第 3 节四路 |

IIC2 的 C4／C5 与编码器冲突；FLEXIO 摄像头推荐接法大量占用 C5–C15，与底盘冲突，排除这两类新增占用。SPI4 已用于 IMU，不作为独立空闲总线；另选 C3／C2／C1 也撞编码器。若将来要共享现有 SPI4，须另行审核片选、时序、频率和驱动访问，本次不更改。UART7 在当前 SDK 没有可用引脚枚举。

### 5.1 GPIO 名称与已有硬件连接

当前 `zf_driver_gpio.h` 提供的丝印名称范围是：

- B0–B3、B9–B31；
- C0–C31；
- D0–D4、D12–D17、D26–D27。

这些只是支持范围，须先扣除底盘及所选外设，再核对板载电路。旧表中的 A0–A29、B4–B8、D5–D11 不能作为本 SDK 的现成空闲引脚。

C4–C15 涉及启动配置脚，库资料有上电时序提醒；现有底盘保持不变，不为新增接口擅自烧 Fuse 或修改启动配置。SWD、存储器及其他未列出的核心板专用信号不作为普通空闲接口。

## 6. 当前串口中断路由

“当前没有初始化”不等于“打开接收中断即可用于新协议”。

| 串口 | 当前 `isr.c` 情况 | 后续接入要求 |
| --- | --- | --- |
| UART1 | 字节送入旧分类协议 `app_link_isr_feed_class_byte()` | 新协议任务中明确接收归属，不能直接沿用旧解析 |
| UART4 | 字节送入旧地图协议 `app_link_isr_feed_map_byte()` | 同上；旧 `pinMap.h` 宏保留不等于当前正在启用 |
| UART5 | 调用摄像头接收回调 | 按所选摄像头或新协议核对回调 |
| UART2／3／6 | RX 分支未实现读取字节 | 不直接打开 RX 中断，须在对应任务实现接收 |
| UART8 | 当前应用无自定义接收入口；Debug 关闭 | 复用或恢复 Debug 时核对中断与引脚 |

本次不改这些 ISR，也不删除 `app_link`；底盘仍使用其地图快照接口。
