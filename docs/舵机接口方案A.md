# 舵机接口方案 A 记录（未实施）

> 日期：2026-10-20
> 状态：**仅记录，未改代码、未改接线**
> 目的：吸盘目前占用舵机接口 2（P17/D0）和 3（P18/D1），需要腾出一个接口给升降机构。
> 触发条件：用户确认要实施时，再按本记录改线与改固件。

## 1. 背景

主板三个标准舵机口：

| 接口 | 引脚 | 当前用途 |
|------|------|----------|
| 舵机 1（P16） | C30，PWM4 子模块 2 A | 旋转舵机（BDS 系列） |
| 舵机 2（P17） | D0，PWM1 子模块 3 A | 泵电子开关信号 |
| 舵机 3（P18） | D1，PWM1 子模块 3 B | 阀电子开关信号 |

关键事实：两个电子开关的红、黑线接在 **P5（UART4）的 5V_EXT / GND**，舵机口只用到**信号脚**。因此把一个信号改到别的 PWM 引脚，就能整口腾出来，不需要改气路或换开关。

## 2. 方案 A 接线

| 线 | 现在 | 方案 A | 说明 |
|----|------|--------|------|
| 泵白线 | P17.1（D0） | 不变 | PWM1 子模块 3 A，50 Hz |
| 泵红/黑 | P5 的 5V_EXT / GND | 不变 | |
| 阀白线 | P18.1（D1） | **D16**（右上“无线模块 UART”排针） | PWM1 子模块 2 A |
| 阀红/黑 | P5 的 5V_EXT / GND | 不变 | 若原本插在 P18 的 VCC/GND，必须移到 P5 |
| P18 | 被阀占用 | **空出** | 升降舵机：信号 P18.1（D1，PWM1 子模块 3 B），电源 VCC_Servo / GND |

改后资源分配：

```text
泵        D0  → PWM1 子模块 3 A  ┐ 同为 50 Hz，可共用周期
升降舵机  D1  → PWM1 子模块 3 B  ┘
阀        D16 → PWM1 子模块 2 A
旋转舵机  C30 → PWM4 子模块 2 A
```

## 3. 实施步骤（确认后再做）

1. 断电，拔掉泵阀负载电源。
2. 把阀白线从 P18.1 改插到 D16；用母对母杜邦延长，注意不要碰到 D17 / GND / 5V。
3. 确认阀的红/黑线在 P5 的 5V_EXT / GND。
4. 万用表确认 P5 5V_EXT 对 GND 约 5 V，D16 对 GND 无异常电压。
5. 改固件（见第 4 节），编译烧录。
6. 先不接负载，示波器测 D16：50 Hz、关约 544 µs、开约 2400 µs；D0 仍正常。
7. 接回泵阀，按原短按流程复测吸附与泄压。
8. 升降舵机装好后接 P18，先空载测行程。

## 5. 风险与注意

- **D16 是无线模块 UART 的 TX（UART8）**。当前 `DEBUG_UART_ENABLE=0` 且未初始化 UART，所以可用；若以后恢复无线调试，应改用 D12/D13（PWM1 子模块 0）或 D14/D15（子模块 1）。
- **P18 的 VCC 是可调 VCC_Servo**，与 P16/P17 共用一路，不是固定 5 V；升降舵机接入后要核算两路舵机电流与电压。
- 阀和泵改到不同子模块后，**不再同一帧装载**；泄压“关泵→开阀→2 s→关阀”的机械先后要靠软件顺序与实测确认，不能沿用原同帧假设。
- 舵机口信号串有 100 Ω 电阻，D16 直连没有；电子开关输入为高阻，不影响。
