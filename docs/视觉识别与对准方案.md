## 3. 光学与安装（决定精度上限）

### 3.1 130° 广角 + QVGA 的现实

130° 视场意味着每个像素覆盖的角度很大。按 130° 对角视场、4:3 传感器估算（**必须实测复核，见 3.2**）：

| 镜头到地面 H | 地面覆盖宽×高 | 地面 px/mm | 顶面 px/mm | 35 mm 方块边长 |
|---|---|---|---|---|
| 100 mm | 343×257 mm | 0.93 | 1.44 | 约 50 px |
| 150 mm | 515×386 mm | 0.62 | 0.81 | 约 28 px |
| 200 mm | 686×515 mm | 0.47 | 0.57 | 约 20 px |
| 250 mm | 858×643 mm | 0.37 | 0.43 | 约 15 px |
| 300 mm | 1029×772 mm | 0.31 | 0.35 | 约 12 px |

“顶面 px/mm”按方块顶面比地面近 35 mm 计算（H′=H−35）。

**结论：**

- 安装高度越低，方块像素越多、中心精度越高。建议镜头到**方块顶面**约 **150 mm**（H≈185 mm 到地面），方块约 28 px；若机械上必须更高，250 mm 时只有约 15 px，识别与形状校验都会明显变难。
- 只使用画面**中心区域**（建议 240×180 ROI）：130° 广角即使“无畸变”，边缘仍有透视拉伸和残余畸变。
- 相机必须刚性固定在车体上，镜头光轴尽量垂直地面；碰撞或拆装后必须复测目标位。

### 3.2 实测视场（不要直接用标称 130°）

在工作高度放一把钢尺，让尺横跨画面左右边缘，读左右边缘对应的实际宽度 `W_meas`（mm）：

- 水平当量 `s_u = 320 / W_meas`（px/mm），垂直方向用同样方法测 `H_meas` 复核；
- 有效水平半角 `θ_h = atan(W_meas / (2H))`，用于判断与标称 130° 的差异；
- 如果左右或上下当量相差超过 2%，说明画面不是正对工作平面，先修机械再谈精度。

### 3.3 安装检查清单

- [ ] 镜头垂直：画面中四个方向的同一段钢尺长度一致
- [ ] 刚性：手推车体不产生画面晃动；线缆有应力释放
- [ ] 遮光：避免阳光直射镜头或工作区，避免车体阴影盖住方块
- [ ] 防撞：镜头不高于吸盘最低行程，避免吸取时碰撞
- [ ] 供电：5V 由整车提供，实测电流余量（模块最大约 1.8 W ≈ 360 mA）

## 4. 图像与曝光设置

| 设置 | 值 | 原因 |
|------|----|------|
| 像素格式 | RGB565 | 颜色识别需要色度信息 |
| 分辨率 | QVGA 320×240 | 模块上限 |
| 自动曝光 | 关闭，固定曝光/增益 | 避免车体移动时亮度跳变导致阈值失效 |
| 自动白平衡 | 关闭，固定增益 | 同上；颜色阈值依赖白平衡 |
| 预热 | 上电后跳过 ≥2 s 帧 | 传感器与自动算法稳定 |
| 帧率 | 目标 15–25 fps | 与 UART 50 Hz 输出匹配 |

固定曝光/白平衡的 API 名称与参数范围以实际固件为准；若该固件不支持关闭自动白平衡，则必须在**实际光照**下标定颜色阈值，并接受光照变化带来的漂移。

## 5. 方块识别（P1 核心）

### 5.1 处理流程

```text
ROI(中心 240×180)
  → LAB 颜色阈值分割（多色预设 + 通用彩色兜底）
  → 形态学开/闭运算 + blob 合并
  → 候选过滤（面积、密度、长宽比、实心度）
  → 方形校验（可选 find_rects 交叉确认）
  → 质心（亚像素）+ 置信度
  → 与目标位比较 → 误差
```

### 5.2 颜色策略

方块有蓝、紫、粉、橙等多种颜色，且 4 面光滑、2 面有纹理：

1. **预设色表**：为已知颜色各存一组 LAB 阈值（6 元组），运行时遍历，取满足条件的最佳 blob。
2. **通用彩色兜底**：当预设都不命中时，用“色度明显偏离灰”的宽阈值（`|a|`、`|b|` 足够大，`L` 在合理范围），可覆盖未登记颜色。
3. **纹理面处理**：纹理会造成高光/阴影碎片，用 `merge=True` 与闭运算把同一方块的多块合并；若仍分裂，按“面积最大 + 与目标点最近”选主块。
4. 阈值必须在实车光照下用 OpenMV IDE 的阈值编辑器重新标定，文档不预设具体数值。

### 5.3 候选过滤

| 条件 | 建议初值 | 说明 |
|------|----------|------|
| 面积 | 由 3.1 节方块像素推算 ±50% | 150 mm 时约 28×28=784 px² |
| 密度 `pixels/(w·h)` | ≥ 0.55 | 排除细长/镂空干扰 |
| 长宽比 `w/h` | 0.6–1.4 | 俯拍正方形应接近 1 |
| 边界裁剪 | blob 不贴 ROI 边缘 | 贴边说明方块不完整或超出视野 |
| 置信度 | ≥ 0.5 | 见 5.4 |

### 5.4 中心与置信度

- 中心优先用 blob 的**矩**计算亚像素质心：`cx = m10/m00`、`cy = m01/m00`；不要只用整数 `cx()`。
- 置信度建议：`conf = min(1, 面积/期望面积) × 密度`，再用连续命中帧数做平滑。
- 输出前对 `(cx, cy)` 做 3–5 帧滑动平均（或一阶低通），抑制阈值抖动。

### 5.5 多目标与误检

- 画面内出现多个方块时，第一版取“离目标点最近”的候选；是否改为“最大面积”需要比赛策略确定。
- 误检防护：候选必须连续命中 ≥2 帧才上报；贴边、面积突变、长宽比异常的帧丢弃。

### 5.6 状态机

```text
SEARCH --(连续 2 帧命中)--> TRACK --(连续 3 帧丢失)--> LOST --> SEARCH
TRACK --(|e| < 死区 且 连续 N 帧)--> ALIGNED
```

`LOST` 状态必须在 UART 帧中明确上报，底盘收到后立即停车。

|------|------|------|
| ROI | 中心 240×180 | 与目标位一起确定 |
| 目标点 (u0,v0) | 待标定 | 见第 6 节 |
| 死区 | 2–3 px（P1）/ 2 mm（P2） | 先松后紧 |
| 连续命中 | 2 帧 | |

### 5.8 参考脚本骨架

```python
import sensor, image, time
from machine import UART

sensor.reset()
sensor.set_pixformat(sensor.RGB565)
sensor.set_framesize(sensor.QVGA)
sensor.set_auto_exposure(False, exposure_us=EXPOSURE_US)
sensor.set_auto_whitebal(False, rgb_gain_db=(R_G, G_G, B_G))
sensor.skip_frames(time=2000)

ROI = (40, 30, 240, 180)
TARGET = (U0, V0)
THRESHOLDS = [BLUE, PURPLE, PINK, ORANGE, ANY_COLOR]

def find_block(img):
    best = None
    for th in THRESHOLDS:
        for b in img.find_blobs([th], roi=ROI, merge=True, margin=6,
                                area_threshold=AREA_MIN,
                                pixels_threshold=AREA_MIN):
            if not (0.6 <= b.w() / b.h() <= 1.4):
                continue
            if b.pixels() / (b.w() * b.h()) < 0.55:
                continue
            m = b.moments()
            if m[0] == 0:
                continue
            cx, cy = m[1] / m[0], m[2] / m[0]
            score = b.pixels()
            if best is None or score > best[0]:
                best = (score, cx, cy)
    return best
```

## 6. 固定目标位与误差定义

### 6.1 工作平面

视觉的工作平面定义为**方块顶面所在平面**（地面上方 35 mm），不是地面。原因见 7.4 节的视差：130° 广角、低高度下，顶面相对底面的径向偏移可达十几毫米。

### 6.2 目标点 (u0,v0) 的标定步骤

1. 用 35 mm 高的垫块/工装，在吸盘轴线正下方放一个中心标记（铅垂线或激光投点）。
2. 把方块放在该位置，顶面中心对准标记。
3. 在 OpenMV IDE 中读取方块质心，记录 `(u0, v0)`。
4. 重复放 5 次，取平均；标准差应 ≤0.5 px，否则先查机械/光照。

这样得到的 `(u0,v0)` 已经包含吸盘轴线与相机轴线的偏移，是“吸盘能吸到”的像素位置，不需要再单独知道相机与吸盘的安装距离。

### 6.3 误差与符号

- 误差：`e_u = cx − u0`，`e_v = cy − v0`（px，P1）；P2 标定后换算为 mm。
- 图像坐标：`+u` 向右，`+v` 向下。
- 车体坐标：`+x` 向右，`+y` 向前（与 `chassis_ctrl` 一致）。
- 标准安装（画面正上方为车头方向）下：`e_u > 0` 说明方块在目标右侧 → 车向右移；`e_v > 0` 说明方块偏后 → 车向后移。
- **符号必须实测确认**，不能只按假设写死：分别让车沿 `+x`、`+y` 移动 50 mm，记录 `Δu`、`Δv`，得到符号表；若相机旋转了 90°/180°，映射随之改变。
- 该映射是**车体固定**的：相机随车刚性安装，所以与全局航向无关；但建议对准期间保持航向（`wz=0`），减少视野旋转、运动模糊和对标定的扰动。

### 6.4 对准判定

- P1：`|e_u|`、`|e_v|` 均小于死区，且连续 N 帧（≥5 帧、约 200 ms）成立 → `ALIGNED`。
- P2：死区换算成 mm（目标 ±2–5 mm），并记录最终误差。
- 调试时可在画面上画出目标框（如以 `(u0,v0)` 为中心、±15 px 的矩形）便于观察，但**判定只用死区**，目标框仅作显示。

## 7. 距离标定（P2）

### 7.1 为什么需要

- 底盘要“移动多少毫米”，只给像素无法换算成速度/位移；
- 对准死区、验收指标都要用 mm；
- 比赛场地尺寸、停点容差也以 mm 计。

### 7.2 五种方法对比

| 方法 | 做法 | 优点 | 局限 |
|------|------|------|------|
| A. 平面单应矩阵（推荐） | 在**方块顶面高度**放标定板（棋盘格/A3 格纸/AprilTag 板），取 ≥4 点（推荐 9–25 点）像素↔mm 对应，最小二乘求 3×3 H | 同时吸收安装倾斜与残余畸变；精度最高 | 需要标定板与 35 mm 垫高工装 |
| B. 钢尺像素当量 | 沿 u、v 方向放钢尺，读多个刻度的像素坐标，线性拟合 px/mm | 直观、器材简单 | 只测尺度，不校正倾斜；边缘区误差大 |
| C. 已知尺寸物体 | 用 35 mm 方块或已知边长板做尺度 `s = 像素边长 / 35` | 不需额外器材 | 受边缘检测、顶面高度、透视影响，只适合快速校验 |
| D. AprilTag 位姿 | 已知 tag 边长 + 相机内参，`find_apriltags(fx,fy,cx,cy)` 直接给平移量 | 单帧得 mm，可在线验证 | 需内参；QVGA 下小 tag 角点精度有限 |
| E. 机械基准 + 相似三角形 | 铅垂线定光轴落点，卷尺/激光测距测 H，按实测 FOV 算当量 | 不依赖图像算法，可交叉验证 | 光轴落点难精确，标称 FOV 不可信 |

### 7.3 推荐组合（可信度最高）

1. **A 做主标定**：在顶面高度铺标定板，取 9–25 个点求 H；标定板方格建议 20 mm。
2. **B 复核中心区当量**：在画面中心 ±50 mm 范围内用钢尺测 3–5 段，与 A 的结果差异应 <2%。
3. **D 或 C 做独立抽查**：用 AprilTag 或 35 mm 方块在 3 个不同位置比较视觉距离与实测距离。
4. **记录**：H 值、标定日期、镜头/固件版本、残差、环境温度与光照。
5. **日常复测**：装拆、碰撞、换场地后，把方块放回目标位读一次质心；偏离 >2 px 就重标。

### 7.4 视差：为什么必须在顶面平面标定

方块顶面比地面高 `h = 35 mm`。若在**地面**标定，而实际观测的是顶面中心，则距离光轴 `r` 处的顶面点会向外偏移：

```text
Δr ≈ r · h / (H − h)
```

H=150 mm、r=50 mm 时 Δr ≈ 15 mm，远超 ±5 mm 目标。处理方法（按优先级）：

1. **在顶面平面标定**（推荐）：标定板垫高 35 mm，或用方块本身在多个已知位置取点；
2. 把目标点放在光轴附近（r 小），使视差可忽略；
3. 按上式做解析校正（仅在无法垫高标定时使用）。

### 7.5 “距离真实可信”的判据

- 标定时的**高度、安装、光照**与实际比赛一致；
- 用**未参与求解**的独立验证点（≥9 个）计算残差，最大残差 ≤ 目标精度的一半（如 ±5 mm → ≤2.5 mm）；
- 静态重复性：同一位置放 10 次，质心标准差 ≤0.5 px，换算后 ≤1 mm；
- 稳定性：连续 30 min 温漂 <1 mm；装拆后复测点偏差 <2 mm；
- 不以标称 FOV（130°）直接换算作为最终结果，只用于交叉检查；
- 标定文件带版本/日期，换镜头或换高度必须重标。

## 8. 通信协议

### 8.1 三种方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| A. 复用 `app_link` 帧（`AA 55 / TYPE / LEN / PAYLOAD / CRC8`），新增视觉误差 TYPE | CRC、状态机、快照机制现成；主控只加一个类型分支 | 与旧业务协议同文件，语义要写清 |
| B. 独立定长帧（如 14 字节） | 简单、解析快、字段独立 | 多一套状态机与 CRC 实现 |
| C. ASCII CSV 行 | OpenMV IDE 串口终端可直接看，调试方便 | 解析开销大、带宽利用率低 |

推荐：**A 作为运行协议，C 作为调试开关**（同一脚本用宏切换）；不新增第二套 CRC，复用 `app_link_compute_crc8`（多项式 0x07）。

### 8.2 建议帧定义（TYPE=0x12，待确认）

```text
AA 55 | 12 | 08 | seq | flags | dx_L dx_H | dy_L dy_H | conf | status | CRC8
```

| 字段 | 类型 | 含义 |
|------|------|------|
| seq | u8 | 视觉端自增，用于丢帧/防重 |
| flags | u8 | bit0 FOUND；bit1 LOW_CONF；bit2 单位=0.1 mm（否则 0.1 px）；bit3 AT_TARGET |
| dx | i16 | 水平误差（右为正） |
| dy | i16 | 垂直误差（下为正） |
| conf | u8 | 0–100 |
| status | u8 | 0=SEARCH，1=TRACK，2=ALIGNED，3=LOST |
| CRC8 | u8 | 覆盖 TYPE..PAYLOAD |

- 输出频率：20–50 Hz；115200 bps 下 14 字节/帧的带宽占用可忽略。
- 超时：主控连续 100 ms 未收到有效帧 → 视为 LOST 并停车。
- 坐标系与单位必须在 flags 中显式标注，避免 P1/P2 混用。

### 8.3 接口与初始化

- 物理接口：XH2.54 的 TX/RX/GND/5V；3.3V 电平与 RT1064 兼容。
- 主控侧候选：LPUART1（B12/B13）或 LPUART4（C16/C17）。
- 现状：当前固件**没有初始化任何 UART**（`app_link` 只保留解析器与地图快照，未见 `uart_init` 调用），因此视觉链路可以独占其中一个，但需要新增初始化与 ISR 路由，并在 `main.c` 的模式中启用。
- 具体用哪个串口、是否复用 `app_link` 的解析器，待 P3 实施前确认。

## 9. 底盘衔接

### 9.1 现状约束

| 约束 | 数值/现状 | 影响 |
|------|-----------|------|
| 公开速度入口 | `chassis_ctrl` 只有 `move_to_*`、`hold_yaw`、`rotate`、`stop`，没有直接的 body 速度接口 | 视觉伺服需要新增入口或走位置指令 |
| 到位窗口 | 位置误差 ≤10 mm（`CHASSIS_TARGET_REACHED_EPSILON_M`）+ 速度 ≤0.12 m/s + 连续 2 拍 | 10 mm 与 ±5 mm 目标同量级，**不能**直接用 `move_to` 做最终对准 |
| 保持退出 | 位置误差 >50 mm（`CHASSIS_POS_HOLD_EXIT_M`）才重启驱动 | 对准后的小扰动会被保持，但精度仍受 10 mm 窗口限制 |
| 保护边界 | 底盘文件受保护，改动需单独授权 | P3 前不动底盘 |

### 9.2 两条路线

| 路线 | 做法 | 精度 | 代价 |
|------|------|------|------|
| R1 停走式 | 视觉给 mm 偏移 → 主控用小步 `move_to`；每次停下再测 | 受 10 mm 到位窗口限制，只能粗对准 | 不改底盘；速度慢 |
| R2 视觉伺服（推荐） | 新增 `chassis_ctrl_set_body_velocity(vx, vy, wz)` 或 `chassis_ctrl_visual_servo_step(ex, ey)`，绕过到位判定 | 可到 ±2–5 mm | 需改底盘入口，必须单独授权 |

建议：R1 用于把方块带入画面中心附近；最后 20–30 mm 用 R2 精对准；R2 落地前，P1 只做识别与误差上报，不闭环。

### 9.3 控制律（R2）

```text
vx = clamp(Kp_x · e_u_mm, −vmax, +vmax)    // 车体 +x 向右
vy = clamp(Kp_y · e_v_mm, −vmax, +vmax)    // 注意符号：e_v 向下为正，前进为 +y
wz = hold_yaw(当前航向)                     // 对准期间不转向
```

- `Kp` 初值 1.0–2.0 (1/s)，`vmax` 粗对准 0.10–0.15 m/s，精对准 0.02–0.03 m/s；
- 死区 2 mm（P2）或 2–3 px（P1）；连续 5 帧满足才判定 ALIGNED；
- 目标丢失、超时（如 5 s）、误差突变（>50 mm）立即停车。

### 9.4 运动模糊与两段式

- 130° 广角 + 较低照度下曝光时间偏长，运动中拖影会拉低质心精度；
- 建议两段式：粗对准允许低速连续运动；进入最后 20 mm 后降速或“停—测—走”；
- 判定 ALIGNED 后必须先停车稳定 ≥100 ms，再让吸盘下降，避免边动边吸。

### 9.5 安全

- 视觉 LOST → 立即停车；
- 吸盘动作前必须满足：ALIGNED + 车速≈0 + 软限位允许；
- 软限位、看门狗、20 ms 闭环节拍保持不变。

## 10. 验收与测试

### 10.1 识别

- 颜色：蓝/紫/粉/橙各 5 次；未知颜色用兜底阈值 5 次；
- 面：光滑面 5 次、纹理面 5 次；
- 姿态：方块旋转 0°/15°/30°/45°；
- 光照：正常/偏暗/偏亮各 5 次；
- 指标：检出率 ≥95%，误检 0，质心重复性 ≤0.5 px。

### 10.2 静态重复性

同一位置放 10 次，记录 `cx, cy` 的均值与标准差；标准差 >0.5 px 时先排查光照与放置误差。

### 10.3 对准（R2 落地后）

初始偏差 10/20/40/60 mm 各 5 次；记录收敛时间、最终误差、超调、是否震荡；目标：最终误差 ≤5 mm，收敛 ≤2 s。

### 10.4 标定验证

独立验证点 ≥9 个，报告最大/平均残差；装拆后复测。

### 10.5 集成

UART 丢帧率、断线重连、上电顺序（先视觉后主控/反之）、SD 卡缺失时的行为。

## 12. 风险与对策

| 风险 | 对策 |
|------|------|
| 130° 广角 + QVGA 分辨率不足 | 降低安装高度；只用中心 ROI；亚像素质心 |
| 泡沫纹理面导致 blob 分裂 | merge + 闭运算；优先光滑面；多帧确认 |
| 颜色随光照漂移 | 固定曝光/白平衡；现场重标阈值；兜底阈值 |
| 顶面视差 | 在顶面平面标定（7.4） |
| 车体振动/镜头松动 | 刚性安装；每次上场复测目标点 |
| UART 延迟/丢帧 | seq + 100 ms 超时停车；低频高置信输出 |
| 底盘到达阈值过粗 | P3 新增视觉伺服入口，不依赖 `move_to` |
| 边动边吸导致偏移 | ALIGNED 后停车 100 ms 再吸 |
