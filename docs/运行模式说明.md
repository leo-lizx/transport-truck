# 运行模式说明（模式 1–9）

> 更新：2026-11-13；对应分支 `transport-local`。
> 本文汇总 `project/user/src/main.c` 中每个运行模式的功能、接线和使用方法。
> 各模块的详细测试步骤见文末链接；表中“验证状态”只记录已有证据，没有实测的不写成已通过。

## 1. 切换模式

运行模式是编译期选择，改 `project/user/src/main.c` 中这一行，然后 **Rebuild All 并重新下载**：

```c
#define MAIN_RUN_MODE                 (MAIN_RUN_MODE_STEPPER_TEST)   /* 当前默认：模式 9 */
```

可选值：

| 编号 | 宏名 | 功能 |
|---|---|---|
| 1 | `MAIN_RUN_MODE_YAW_HOLD` | 航向保持调试 |
| 2 | `MAIN_RUN_MODE_SINGLE_WHEEL` | 单轮 PID 调试 |
| 3 | `MAIN_RUN_MODE_POINT_NAV` | 旧网格航点导航 |
| 4 | `MAIN_RUN_MODE_SUCTION_TEST` | 吸盘按键测试 |
| 5 | `MAIN_RUN_MODE_SERVO_TEST` | 舵机 75–105° 往返 |
| 6 | `MAIN_RUN_MODE_SERVO_SEQUENCE` | 舵机上电单周期 90→0→180→90 |
| 7 | `MAIN_RUN_MODE_STORAGE_NAV` | 存放区 5 点导航，每点停 1 s |
| 8 | `MAIN_RUN_MODE_STORAGE_NAV_FAST` | 同模式 7，每点停 0.3 s |
| 9 | `MAIN_RUN_MODE_STEPPER_TEST` | 升降步进回原点与点动 |

> 换模式后只按 Download、不重新编译，板子里跑的还是旧模式。这个错误以前出现过，
> 见 `.hecateflow/lessons/stale-flash-after-pin-change.md`。

编译：IAR 打开 `project/iar/rt1064.eww`，配置 `nor_sdram_zf_dtcm`，Project → Rebuild All，再 Download and Debug（Ctrl+D）。

## 2. 公共接线与节拍

### 2.1 所有模式共用

| 项目 | 接法 | 说明 |
|---|---|---|
| 主板供电 | 电池接 P19/P20（1=VCCBAT，2=GND） | 只接 USB 时电机、舵机、泵阀都不能工作 |
| 下载调试 | CMSIS-DAP / J-Link 接 SWD | IAR Live Watch 看变量 |
| 看门狗 | RTWDOG 约 2 s | 主循环卡住约 2 s 后复位；调试暂停不会触发（已开 debug 模式） |
| 调试串口 | UART8（D16 TX / D17 RX，115200） | 当前 `DEBUG_UART_ENABLE = 0`，所有 `printf` 都不输出 |
| 板载按键 | K1=C15、K2=C14、K3=C13、K4=C12，按下为低 | 物理按键与 K1–K4 的对应要上板核对 |

### 2.2 底盘接线（模式 1、2、3、7、8 使用；4、5、6 会初始化但保持停止）

| 功能 | 引脚 | 主板接口 |
|---|---|---|
| 左前轮 LF | PWM C11，DIR C10 | P9 |
| 右前轮 RF | PWM D3，DIR D2 | P9 |
| 左后轮 LB | PWM C6，DIR C7 | P8 |
| 右后轮 RB | PWM C8，DIR C9 | P8 |
| LF / RF / LB / RB 编码器 | C5·C25 / C3·C4 / C0·C1 / C2·C24 | 编码器 4 / 3 / 1 / 2（P10 / P11 / P13 / P12） |
| IMU660RB | SPI4：SCK C23，MOSI C22，MISO C21，CS C20 | P3 |

底盘线序和极性已经实车标定，**不要改动**。详细针号见 [PINOUT.md](PINOUT.md)。

### 2.3 中断节拍

| 模式 | PIT_CH0（5 ms） | PIT_CH1（20 ms） | 其他 |
|---|---|---|---|
| 1–8 | IMU 姿态采样 + 唤醒主循环 | 编码器、里程计、PID、电机输出 | — |
| 9 | 不启动 | 不启动 | PIT_CH2 每 5 ms 只唤醒主循环；GPT1 产生步进脉冲 |

### 2.4 IMU 标定

模式 1–8 上电后执行 `chassis_ctrl_init()`，其中包括 IMU 零偏标定（约 1 s）。
**上电到标定结束前车体必须静止**，否则航向会一开始就漂。模式 9 不初始化底盘和 IMU。

## 3. 模式 1：航向保持调试

**功能**：底盘不平移，只用 IMU 航向闭环把车头锁在 **180°**（`MAIN_POS_NAV_HOLD_YAW_DEG`）。
上电时的车头方向记为 0°，所以上电后车会原地转 180° 再保持。用来调航向环参数、检查 IMU 极性。

**接线**：2.2 全部底盘接线 + 电池。

**使用**：
1. 车放在地面，上电后静止约 1 s 等 IMU 标定。
2. 车原地转半圈后停住。用手轻推车头，松手后应转回原方向，不振荡。
3. 调试时在 Live Watch 看 `chassis_ctrl_attitude_debug_get_state()` 对应的目标角、当前角、误差和角速度指令。
   打开调试串口后，主循环每 50 ms 输出一次 12 通道数据（VOFA+ FireWater）。

**判断**：转向方向反了或持续加速旋转，先查 `CHASSIS_IMU_YAW_SIGN`，不要先改 PID。

**验证状态**：IAR 编译通过（2026-10-17）。

## 4. 模式 2：单轮 PID 调试

**功能**：只让一个轮子做速度闭环，其他三个轮目标速度为 0。默认调 **RB（右后轮）**，
目标 **0.10 m/s**，用 `KP=200 / KI=50 / KD=10` 覆盖该轮参数。用来核对单个轮子的电机方向、编码器方向和 PID 响应。

**接线**：2.2 底盘接线 + 电池。**建议把车架空**，让轮子离地。

**使用**：
1. 在 `main.c` 修改：
   - `MAIN_PID_DEBUG_WHEEL_INDEX`：0=LF，1=RF，2=LB，3=RB；
   - `MAIN_PID_DEBUG_TARGET_MPS`：目标轮速；
   - `MAIN_PID_DEBUG_FORCE_PID` 和 `MAIN_PID_DEBUG_KP/KI/KD`：是否覆盖、覆盖值。
2. 编译下载，架空上电，被调的轮子应以恒定速度朝“车前进方向”转。
3. 打开调试串口时每 100 ms 输出目标轮速和实际轮速；未开串口用 Live Watch 看
   `chassis_ctrl_get_wheel_feedback_snapshot()` 的结果。

**判断**：
- 轮子转向和前进方向相反：改 `configChassis.h` 极性段的 `MOTOR_*_OUTPUT_DIR`。
- 轮子在转、反馈却是负值：改 `ENCODER_*_DIR`。
- 手转某个轮子时别的轮子的反馈在变：编码器接错位置，查 `pinMap.h`。

**验证状态**：IAR 编译通过；单轮参数来自前期实车调试。

## 5. 模式 3：旧网格航点导航

**功能**：原工程留下的 29 个网格航点测试路线（格子单位，起点 (1, 5.5)，航向全程 0°），
用来检查定点导航和到位判定。**这不是运输赛道路线。**

**接线**：2.2 底盘接线 + 电池。场地需要约 2.8 m × 2.0 m。

**使用**：
1. 车放在起点，车头朝 +y，上电静止。
2. 暖机 1 s 后依次走航点，每到一点立即走下一点，走完停在终点。
3. Live Watch 看 `g_chassis_arrival_count`（到达次数）；打开调试串口时每 50 ms 输出位姿、目标、距离平方、航向、到达标志和航点序号。
4. 航点表在 `main.c` 的 `s_wps[]`，格式 `{x格, y格, yaw°}`。

**验证状态**：IAR 编译通过；路线是旧场地参数，未在运输赛道上验证。

## 6. 模式 4：吸盘按键测试

**功能**：按住 K1（C15）吸附，松开后关泵、电磁阀通电泄压 2 s，再关阀。底盘保持停止。

**接线**：

| 线 | 接到 |
|---|---|
| 泵电子开关白线（信号） | P17.1（D0） |
| 阀电子开关白线（信号） | P18.1（D1） |
| 两个电子开关红线 | P5.1（5V_EXT） |
| 两个电子开关黑线 | P5.2（GND） |
| P17.2 / P18.2 | **不接**，是可调舵机电源 |
| 气路 | 阀 1 口接吸盘、3 口接泵吸气口、2 口通大气 |

**使用**：
1. 上电时如果正按着 K1，要先松开，程序才解锁。
2. 按住 K1：泵开、阀关，开始吸附。
3. 松开 K1：泵关、阀开，泄压 2 s 后阀关。泄压期间再按 K1 会重新吸附。
4. 每次只按 1–3 秒。**本模式没有泵长时间运行保护，不要一直按住。**

| 阶段 | 泵 | 阀 |
|---|---|---|
| 初始化 / 待机 | 关 | 关 |
| 按住 K1 | 开 | 关 |
| 松开后 0–2 s | 关 | 开 |
| 松开满 2 s | 关 | 关 |

信号波形：50 Hz，关约 544 µs、开约 2400 µs（复现资料里 Arduino `Servo.write(0/180)` 的默认值）。

**验证状态**：IAR/MDK 编译通过，主机测试 19 用例 205 断言 0 失败；电子开关、气路和实际吸附未记录实测结果。
详见 [吸盘模式4接线与测试.md](吸盘模式4接线与测试.md)。

## 7. 模式 5：舵机往返测试

**功能**：FS5323M 舵机上电先到 90°，然后在 **75°–105°** 之间每 50 ms 走 1° 来回扫动。底盘保持停止。

**接线**：

| 线 | 接到 |
|---|---|
| 舵机信号 | P16.1（C30，PWM4 子模块 2 A） |
| 舵机电源 | P16.2（VCC_Servo，可调，三个舵机口共用） |
| 舵机地 | P16.3（GND） |

**使用**：
1. 先**卸掉机构**，舵机空载。
2. 上电前测一下 VCC_Servo 电压，应在舵机额定 4.8–6 V 范围内。
3. 上电后舵机应在中位附近小幅来回摆动。
4. 参数在 `config/configServo.h`：`SERVO_TEST_MIN_DEG`、`SERVO_TEST_MAX_DEG`、`SERVO_TEST_STEP_DEG`、`SERVO_TEST_STEP_MS`。

PWM：300 Hz，0.5 ms→0°、1.5 ms→90°、2.5 ms→180°。指令角度不等于实际角度，装机后要实测校准。

**验证状态**：编译通过；300 Hz + C30 的组合在 2026-10-20 的对照测试中舵机能转。

## 8. 模式 6：舵机上电单周期

**功能**：上电停在 90°，之后每隔 1.5 s 依次转到 0° → 180° → 90°，停在 90° 不再动作。用来确认全行程端点。底盘保持停止。

**接线**：与模式 5 相同。

**使用**：
1. **必须空载**，0° 和 180° 是行程两端。
2. 上电后不用按键，约 4.5 s 完成一个周期。重新上电会再跑一次。
3. 观察两端是否撞到机械限位、是否有异响。

| 时间 | 指令角 |
|---|---|
| 0 s | 90° |
| 1.5 s | 0° |
| 3.0 s | 180° |
| 4.5 s | 90°（结束） |

**验证状态**：编译通过，主机测试通过；端点空载实测未记录。

## 9. 模式 7：存放区 5 点导航（停 1 s）

**功能**：从 (0, 0) 出发、车头朝 +y，用 `move_to_m_direct` 走直线依次到 5 个停顿点，
每点停 1 s，最后一点停完后停车。车头全程不转。

| 序号 | 下发 x（m） | y（m） | 说明 |
|---|---|---|---|
| 1 | +0.200 | 0.475 | 地图 x = −0.200 |
| 2 | −0.200 | 0.975 | 地图 x = +0.200 |
| 3 | +0.200 | 1.475 | 地图 x = −0.200 |
| 4 | −0.200 | 1.975 | 地图 x = +0.200 |
| 5 | 0.000 | 2.275 | — |

下发 x 是地图 x 取反后的值，因为当前底盘内部 +x 实际朝左。

**接线**：2.2 底盘接线 + 电池。

**使用**：
1. 车中心放在起点 (0, 0)，车头沿赛道朝前，上电后静止。
2. 暖机 1 s 后开始走。每段到达后停顿，再走下一段。
3. 超时保护：单段 6 s 还没判到达、但已在目标 6 cm 内，强制进入停顿；12 s 还没接近，**整车停车，后面的停点不再走**。
4. 航点表在 `main.c` 的模式 7/8 分支 `s_wps[]`。

**已知问题**（见下一阶段计划 P0）：
- 每段的保持航向取下发时的实际航向，误差会逐段累积；
- 超时后停车会丢掉剩余停点，比赛里应该改成跳到下一点；
- 到位窗口 3 cm 与释放阈值 5 cm 间隔偏小。

**验证状态**：IAR 0 error 0 warning；首段方向实车观察过，修正后未复测。

## 10. 模式 8：存放区 5 点导航（停 0.3 s）

**功能、接线、使用**：与模式 7 完全相同，只是每点停顿 0.3 s（`MAIN_STORAGE_NAV_FAST_DWELL_TICKS`）。

**验证状态**：IAR 和 MDK 0 error 0 warning；0.3 s 停顿未实车验证。

## 11. 模式 9：升降步进测试（当前默认）

**功能**：控制 FSK30 丝杆模组上的步进电机。上电自动回原点，然后可以用按键点动。
**不初始化底盘、IMU 和电机 PWM**，主板不接底盘也能跑。

**接线**：

| 线 | 接到 |
|---|---|
| 驱动器 V+ / V- | 外部 12 V 电源（限流 2 A），**不能接主板电池输出** |
| 驱动器 P+（脉冲） | D12（P7 的 SCK 针） |
| 驱动器 D+（方向） | C16（P5 的 TX 针，第 4 针） |
| 驱动器 P- 、D- | 主板 GND |
| 电机 A 相 / B 相 | 细黑·绿 / 细红·蓝 |
| 限位开关 | P21.1（D4）和 P21.3（GND）；不要接 P21.2（3V3） |
| 公共地 | 驱动器电源地接主板 GND |

**参数**：导程 12 mm，1/8 细分，约 133.3 步/mm（按 1.8° 电机计算，待核对铭牌）。

**使用**：
1. 断电时用手把滑台推到行程中间。
2. 先给驱动器上电，确认电流约 0.3 A、L1/L2 不亮。
3. 再给主板上电，手放在驱动器电源开关上。1 s 后滑台以 5 mm/s 朝开关方向走：
   碰到开关后退 2 mm，再以 2 mm/s 慢碰一次定零点，最后停在离开关 2 mm 处。
4. 按键：

| 按键 | 动作 |
|---|---|
| K1（C15） | 远离开关 10 mm，最多到 40 mm |
| K2（C14） | 朝开关 10 mm，最少到 1 mm |
| K3（C13） | 重新回原点 |
| K4（C12） | 任何时候立即停止；按 K3 恢复 |

5. Live Watch 看 `s_state`：0 等待，1 快速找开关，2 退出，3 慢速找开关，4 去就绪位，5 就绪，6 找不到开关，7 急停。
6. 方向反了（回原点时远离开关）：按 K4，把 `configStepper.h` 的 `STEPPER_DIR_LEVEL_AWAY_FROM_HOME` 改为 `0U` 后重新编译。

**验证状态**：IAR 0 error 0 warning，主机测试 18 用例 0 失败；实测 D12 有脉冲输出。
首块 RMN28 驱动板已判定损坏（不响应脉冲），**整机运动未验证**，待新驱动器到货。
详见 [升降步进模式9接线与测试.md](升降步进模式9接线与测试.md)。

## 12. 引脚占用总表

| 引脚 | 用途 | 使用的模式 |
|---|---|---|
| C6–C11、D2、D3 | 四轮电机 PWM/DIR | 1–8 |
| C0–C5、C24、C25 | 四路编码器 | 1–8 |
| C20–C23 | IMU（SPI4） | 1–8 |
| D0 / D1 | 泵 / 阀电子开关 | 4 |
| C30 | 旋转舵机 | 5、6 |
| D12 / C16 | 步进脉冲 / 方向 | 9 |
| D4 | 升降限位开关 | 9 |
| C15 | K1 | 4、9 |
| C12–C14 | K4–K2 | 9 |

D0/D1、C30、D12/C16/D4 之间没有冲突，后续整车联动时可以同时使用。
占用 D12 后，P7 不能再插 SPI 无线模块；C16 已作 DIR，P5 不得同时接 UART4 外设或启用 UART4 TX。
