# 运输车主控基础工程

本工程从本地 RT1064 推箱子工程精简而来，保留四麦克纳姆轮底盘、IMU、编码器、PID、MPC 和串口通信基础。推箱子业务、PC 验证工具、视觉 Python 程序和旧菜单已移除；运输任务逻辑与新菜单待构建。

## 目录结构

```text
transport-truck/
├── project/
│   ├── code/
│   │   ├── config/       # 引脚映射、底盘参数及方向极性
│   │   ├── chassis_*     # 底盘驱动、控制、运动规划及区域判定
│   │   ├── app_link.c/h  # 保留的串口协议与地图快照
│   │   ├── app_suction_test.c/h # C15 吸盘独立测试
│   │   └── drv_suction.c/h      # 泵阀电子开关 PWM 驱动
│   ├── user/            # main.c 和中断入口 isr.c
│   ├── iar/             # IAR 工程
│   └── mdk/             # MDK 工程
├── libraries/           # 逐飞 SDK、外设驱动及许可证
└── docs/                # PINOUT 引脚资料
```

## 当前入口

`project/user/src/main.c` 保留原编号 1（航向保持调试）、2（单轮 PID 调试）、3（定点导航），新增编号 4（吸盘独立测试）、5（FS5323M 舵机扫动测试）和 6（舵机上电序列测试）；当前默认 6。切回其它模式时改 `MAIN_RUN_MODE` 即可。模式 4 中底盘保持停止，稳定松开 C15 解锁后，按住吸附、松手关泵并泄压 2 秒，再关闭电磁阀。模式 5 底盘停止，舵机在 75–105° 之间每 50 ms 走 1° 往返（P16/C30，300 Hz，脉宽用官方例程公式）。模式 6 上电自动执行一个周期 90°→0°→180°→90°，每次转动后停顿 1.5 s，结束停在 90° 不再动作，无需按键；底盘 STOP，仍用 P16/C30、300Hz。**0–180° 对应 0.5–2.5ms，在 FS5323M 的 500–2500µs 额定量程内；首次仍须卸载机构、空载确认端点与机械限位，指令角度不代表实际角度已校准。**旧推箱、视觉测试、主板测试和菜单入口已清除。PIT_CH0 每 5ms 更新姿态，PIT_CH1 每 20ms 执行底盘闭环。

现有 PID 参数、航向保持目标和定点导航的 29 个有效航点保持原值；这些仍是原工程的测试配置，新运输赛道的路线与坐标后续单独确定。

2026-10-17，模式 1／2／3／4 均通过 IAR 9.2 的 `nor_sdram_zf_dtcm` 配置编译与链接验证。吸盘应用主机测试为 19 个用例、205 条断言、0 失败；未执行烧录、波形或实物验证。2026-10-19 修正 `chassis_pid.c` 调试打印的空表达式告警，IAR 重建 0 warning。

硬件引脚、极性和控制参数仍集中在 `project/code/config/pinMap.h` 与 `configChassis.h`。`app_link` 的既有地图快照保留给底盘软限位使用；新的运输业务和通信初始化后续按任务要求构建。
