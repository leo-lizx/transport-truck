# 视觉最小验证（OpenART Plus + OpenMV）

> 目录：`vision/`；固件工程不编译此目录。
> 目标：物块在画面中心标定一次，之后移动物块，实时输出相对标定中心的像素距离。

## 1. 90° 还是 130° 镜头

两者都按 QVGA 320×240、4:3、对角视场估算；`H` 是镜头到**方块顶面**的距离。

| H（镜头→顶面） | 90° 覆盖宽 | 90° px/mm | 90° 方块边长 | 130° 覆盖宽 | 130° px/mm | 130° 方块边长 |
|---|---|---|---|---|---|---|
| 100 mm | 160 mm | 2.00 | 70 px | 343 mm | 0.93 | 33 px |
| 150 mm | 240 mm | 1.33 | 47 px | 515 mm | 0.62 | 22 px |
| 200 mm | 320 mm | 1.00 | 35 px | 686 mm | 0.47 | 16 px |
| 250 mm | 400 mm | 0.80 | 28 px | 858 mm | 0.37 | 13 px |

**结论：当前任务选 90°。**

- 同样高度下，90° 的像素当量约为 130° 的 2.1–2.2 倍，质心更稳、形状过滤更可靠；
- 90° 画面边缘的透视拉伸更小，颜色阈值在不同位置更一致；
- 代价是覆盖范围变小：H=150 mm 时只有 240×180 mm。只要粗定位（惯导/停点）能把物块带到画面内，这个范围足够；如果实际停车偏差可能超过 ±60 mm，再用 130° 做“大范围找块”，找到后切换 90° 精对准。

标称 90°/130° 可能是对角或水平视场，且实际装配有偏差，**必须按方案文档 3.2 节实测**可见宽度，再算 px/mm。

## 2. 脚本做什么

`main.py` 分两个阶段：

1. **标定（自动，一次）**
   - 把 3.5 cm 物块放到画面中心；
   - 脚本用“任意高饱和颜色”的粗阈值找到它，要求质心距画面中心 ≤30 px、连续 12 帧稳定；
   - 锁定后记录两样东西：标定质心 `(u0, v0)`，以及从该物块学到的 LAB 颜色阈值；
   - 屏幕出现 `LOCKED`，串口打印 `LOCKED target=(...) th=(...)`。
2. **追踪（实时）**
   - 每帧用学到的颜色阈值找物块，优先跟上一帧最近的候选；
   - 计算 `dx = cx - u0`、`dy = cy - v0`、`d = sqrt(dx² + dy²)`（像素）；
   - 屏幕上画标定十字、目标框、当前质心和连线，并显示数值；
   - 连续 12 帧找不到 → `LOST`。

不包含：毫米标定、UART 发送、底盘控制。这些按方案文档后续阶段做。

## 3. 运行步骤

1. 把 `main.py` 放 SD 卡根目录（脱机运行），或用 OpenMV IDE 打开后点运行；
2. 上电/运行后，把物块放到画面中心，保持不动；
3. 等屏幕出现 `LOCKED`（约 1–2 秒稳定后）；
4. 移动物块，观察屏幕上的 `dx / dy / d` 与串口 CSV；
5. 重新标定：停止脚本再运行一次。

> 使用 UART/GPIO 时才需要 SD 卡根目录的 `cmm_cfg.csv`、`cmm_load.py`；本脚本只用摄像头，不需要。

## 4. 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `CENTER_X / CENTER_Y` | 160 / 120 | 标定锚点。现在用画面中心；以后要改成吸盘对应的像素位置，只改这两个值 |
| `CENTER_TOL_PX` | 30 | 标定时质心允许偏离锚点的范围 |
| `CALIB_STABLE_FRAMES` | 12 | 连续稳定帧数，越大越稳、标定越慢 |
| `STABLE_DELTA_PX` | 1.5 | 相邻帧质心变化阈值 |
| `LOST_FRAMES` | 12 | 连续丢失帧数 |
| `AREA_MIN/MAX` | 200 / 9000 | 候选面积范围，按实际高度调整 |
| `DENSITY_MIN` | 0.45 | 像素数/外接矩形面积 |
| `ASPECT_MIN/MAX` | 0.5 / 2.0 | 宽高比，俯拍方块应接近 1 |
| `PX_PER_MM` | 0 | 已知像素当量时填入，屏幕上同时显示 mm |

## 5. 输出格式

串口每帧一行 CSV：

```text
时间ms,found,cx,cy,dx,dy,dist_px,面积,fps
12345,1,180.42,95.10,20.42,-24.90,32.20,812,21.7
```

丢失时：

```text
12345,0,-1,-1,-1,-1,-1,0,21.7
```

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| 一直不 LOCKED | 物块不在中心 ±30 px、面积超范围、或颜色饱和度低；看屏幕提示与 `AREA_MIN` |
| LOCKED 后频繁 LOST | 光照变化、物块移出画面、阈值过窄；重新标定或固定曝光 |
| 误锁到其他彩色物体 | 清走画面中心附近的其他彩色物体；本脚本按“离中心最近”选候选 |
| 数值抖动大 | 降低曝光时间/增加补光；检查物块是否在运动模糊 |
| 换面后丢失 | 纹理面与光滑面亮度不同；用实际要吸的那一面标定 |
